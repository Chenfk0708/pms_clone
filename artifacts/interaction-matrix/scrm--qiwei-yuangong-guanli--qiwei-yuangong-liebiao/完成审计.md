## 关键审计点

1. 目标站当前账号可见主体不是员工表格，而是订阅门槛页；本地交付按该真实可见态承接，没有臆造未取证到的员工管理 CRUD。
2. 页面正文已移除 `mock provider`、`未接入`、`后端未完成` 等开发态提示。
3. 服务层统一输出 `{ code, message, data, traceId, timestamp }` 契约，并通过隐藏 contract 节点暴露调试证据。
4. `重试` 不再只是改 UI，而是会重新触发一次真实加载流程。
5. 自动化验证没有再走全站 `src/App.tsx` 主入口，而是改为页面专用 harness，规避了无关页面导入错误导致的空白页假失败。

## 外部阻塞

全量主入口仍受仓库其他页面影响，不能把全站 `vite` 启动或 `npm run build` 的红灯归因到本页。当前已确认的外部阻塞包括：

- `src/App.tsx` 仍引用缺失的 `./pages/OrderLedgerPage`
- `src/pages/IncomeReportPage.tsx`、`src/services/incomeReport.ts` 存在类型不一致
- `src/pages/ReportPage.tsx`、`src/services/aiGlobalData.ts`、`src/services/globalSetting.ts` 存在未使用变量或字面量类型不匹配
- `src/services/presaleSalesReport.ts` 仍有 `undefined` 传参导致的类型错误

因此，本页完成证据以“页面专用 harness + 专项 Playwright + 本地三态取证”为准。
