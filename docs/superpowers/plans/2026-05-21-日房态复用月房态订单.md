# 日房态复用月房态订单 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让日房态左侧直接复用月房态当天订单数据与 hover/click 详情交互。

**Architecture:** 把月房态中“订单单元数据适配”和“订单详情抽屉”拆成可复用的纯渲染/纯数据层，日房态只负责把今天对应的房态数据映射成同一套订单单元模型，再复用同一份悬浮卡与详情抽屉。这样日房态不再维护独立的订单展示逻辑，只保留页面布局与筛选壳。

**Tech Stack:** React, TypeScript, Playwright, Vite
