# 消息通知独立页 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将顶栏消息图标承接的页面替换为独立复刻页，保留现有通知服务契约与交互能力，同时去掉“设置子页”观感。

**Architecture:** 复用现有 `/setting/notification` 与 `/setting/wechatPushSetting` 路由和 `NotificationSettingPage` 数据流，只调整 `AppShell` 对该路由的壳层归类，并重写通知页的 JSX 结构与 CSS 视觉风格。测试先锁定消息图标点击行为和通知页的独立页面特征，再做实现以避免误回归到设置页。

**Tech Stack:** React 19, React Router 7, TypeScript, CSS, Playwright

---
